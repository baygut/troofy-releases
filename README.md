# troofy releases

Signed, notarized builds of troofy for Apple silicon Macs, and the files the app reads to update itself. The source code is private.

- **Install:** [troofy-stable.dmg](https://github.com/baygut/troofy-releases/releases/latest/download/troofy-stable.dmg). After the first install, troofy updates itself.
- **Beta:** the newest pre-release below. Switch channels in troofy under Settings → Updates.

Releases are published by CI; please don't upload files by hand. `config.json` holds the oldest version allowed to run (see "Set minimum version" in the source repo).
